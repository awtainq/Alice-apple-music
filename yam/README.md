# Apple Music для Luna · YAM

Пакет `awtainq/apple-music` содержит готовый `.yap` и небольшую нативную команду
его импорта в Luna. Проверена рутованная Станция Миди (`yandexmidi`), ARM64.

## Установка

```sh
yam install awtainq/apple-music
awtainq-apple-music
```

На колонке должна быть запущена совместимая Luna с API на `127.0.0.1:8098`,
разрешением `allow_plugin_binaries = true` и Entware `/opt/bin/ffmpeg`.
Зависимость `yam/luna >=0.2.7` устанавливает файлы хоста, но YAM пока не
запускает сервисы автоматически. Настройте запуск самой Luna отдельно.
Если API Luna слушает другой порт, укажите `awtainq-apple-music --port PORT`.
Порт 8099 нужен плееру: Luna должна слушать отдельный порт.

Команда загружает включённый в пакет `.yap` через локальный API Luna. Она не
подключается к внешним серверам и не читает токены аккаунтов. Бинарные плагины
из общего дерева YAM текущая Luna пока отклоняет, поэтому нужен явный импорт.
Пакет не обходит это ограничение и не добавляет скрытые init-скрипты или hooks.

Для первой установки подготовьте собственный профиль в соседнем с Luna
`plugins/` каталоге `apple-music-private`, затем запросите запуск:

```sh
awtainq-apple-music --enable-only
```

[Профиль и авторизация](https://github.com/awtainq/Alice-apple-music/blob/main/docs/AUTH.md).
Если профиль уже готов, импорт и запрос запуска можно объединить:

```sh
awtainq-apple-music --enable
```

Импорт останавливает предыдущий сервис перед обновлением `.yap`. Профиль и
очередь сохраняются; очередь восстанавливается на паузе. Скажите «Алиса,
продолжай» или включите песню по голосу.

## Обновление и удаление

После обновления через YAM повторите `awtainq-apple-music --enable`, чтобы
импортировать новую версию в Luna. При ошибке загрузки запуск не запрашивается.

YAM владеет только командой импорта и исходным `.yap`. Импортированной копией
управляет Luna: перед полным удалением отключите `alice-apple-music` в Luna и
удалите его там, затем выполните `yam remove awtainq/apple-music`.
Личный профиль вне пакета удаляется только вручную владельцем.
