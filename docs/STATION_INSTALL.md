# Полный плеер на Станции 2

Проверено на домашней Станции 2 (`yandexmidi`), aarch64, Entware Python 3.13.9,
glibc 2.27, FFmpeg 6.1.4. Требуется уже настроенный root и Entware.

## Что перенесено

Apple Music, очередь, рекомендации, предзагрузка, распознавание музыкальных фраз,
короткие слова без обращения и локальная озвучка работают одним процессом Python.
SSH, VPS, Docker, Google Cloud и навык для музыкальных команд не нужны.
Обычные сетевые запросы к Apple и Яндексу по-прежнему требуют интернет.

Плеер и аудиосервер слушают только `127.0.0.1:8099`, Glagol используется на
`127.0.0.1:1961`, локальный голосовой канал — `127.0.0.1:9875`.
Короткие команды читаются напрямую из локального `maind.log` с поддержкой ротации.
Сетевые порты наружу не открываются.

## Установка

1. Установите Entware Python 3.13, FFmpeg и CA bundle. В проверенной установке
   Python уже был установлен; дополнительно выполнено `/opt/bin/opkg install ffmpeg ca-bundle`.
2. Распакуйте ARM64-комплект в `/data/opt/alice-music`. Каталог `vendor` содержит
   зависимости под CPython 3.13/aarch64/glibc; это не библиотеки для Mac или x86.
   Подготовка из исходников: установить `requirements-direct.txt` для целевой платформы.
   Готовый Python, FFmpeg и личные ресурсы авторизации в архив не входят.
3. Скопируйте файлы `deploy/station/` в каталог плеера. Создайте `private/` с правами `700`,
   сохраните личный `config.json` по примеру и свои уже авторизованные `client_id.bin`
   и `private_key.pem`. Файлы — `600`, не публикуйте их. Первичная авторизация описана
   в `docs/AUTH.md`; готового мастера входа в этот комплект не входит.
4. Остановите прежний плеер и его голосовые мосты на VPS или Mac, если они управляли
   той же Станцией. Сохраните конфигурацию и очередь для отката.
5. Запустите `chmod 700 /data/opt/alice-music/launch.sh`, затем
   `/data/opt/alice-music/launch.sh start`.
6. Для загрузки при включении скопируйте `S99zzalice-music` в `/etc/init.d/`, дайте права `755`.
   Это изменение корневой ФС: временно перемонтируйте `/` в `rw`, после записи и `sync`
   верните `ro`. Служба ждёт появления `/data`, Entware и конфигурации до 120 секунд.

Рабочие команды:

```sh
/data/opt/alice-music/launch.sh status
/opt/bin/python3 /data/opt/alice-music/control.py
/opt/bin/python3 /data/opt/alice-music/control.py resume
/opt/bin/python3 /data/opt/alice-music/control.py pause
tail -20 /tmp/alice-music.log
```

## Память и хранение

- Измеренный RSS после запуска и подготовки песни: около 57 МиБ; это не верхний лимит
  для любых песен и очередей. Процесс FFmpeg во время подготовки требует дополнительную память.
- На проверенном устройстве после установки оставалось примерно 137 МиБ флеш-памяти.
  Эти цифры относятся к одной конкретной установке.
- `vendor` и код — около 28 МиБ на диске; архив без Python/FFmpeg/личных данных — около 6,5 МиБ.
- Аудиокэш лежит в `/tmp/alice-music-cache` (RAM), предзагружается один следующий трек.
  В конфигурации целевой объём 32 МиБ, два файла. Текущая и следующая песни защищены от удаления,
  поэтому при крупных треках целевой объём может быть превышен. Загрузка одного файла ограничена 32 МиБ.
- Журнал в RAM ограничен двумя файлами по 256 КиБ. При перезагрузке кэш и журналы очищаются.
- Очередь в `private/queue.json` сохраняется на флеш при смене трека и примерно раз в минуту.
  После перезапуска очередь восстанавливается на паузе; для запуска скажите «Алиса, продолжай».
- Supervisor перезапускает Python после сбоя; Docker и systemd на колонке не используются.

## Проверка и откат

На устройстве проверены получение и подготовка песни из Apple Music, локальный HTTP-поток,
продолжение с сохранённой позиции, автоматический следующий трек. Пользователь подтвердил
короткое «дальше» и озвучивание названия. Автозапуск установлен; аппаратная перезагрузка
в этой проверке не выполнялась.

Для отката остановите `/data/opt/alice-music/launch.sh stop` и удалите только установленный
нами `/etc/init.d/S99zzalice-music` (с временным `rw` и возвратом `ro`). Затем восстановите
предыдущую службу VPS/Mac и передайте ей актуальную очередь. Не включайте оба плеера сразу.
Установленные пакеты Entware и пользовательский Python при откате не удаляются.

## Сосуществование с AirPlay

Для установленного Station-airplay 1.4.14 и совместимой Luna можно добавить в личный config.json `"airplay_bus":"/run/station-airplay/private-bus"`. Зависимость `dbus-next` входит в requirements-direct.txt. Плеер уступит звук AirPlay и приостановит свою очередь. [Подробности проверенной установки и откат](AIRPLAY_COEXISTENCE.md).
