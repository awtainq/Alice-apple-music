# Личная авторизация

Установщик не выдаёт аккаунты, подписки, токены или данные клиента воспроизведения. Для первой установки нужен **свой уже авторизованный профиль**. При обновлении установленного мода профиль сохраняется на колонке; повторно передавать его не нужно.

## Локальная установка на Станцию

Создайте папку `my-profile/` на компьютере. В ней должны быть:

| Файл / поле в config.json | Что требуется |
| --- | --- |
| `apple_app_token` | Собственный авторизованный app/developer token Apple Music-клиента |
| `apple_user_token` | Пользовательский токен владельца действующей подписки Apple Music |
| `yandex_music_token` | Токен владельца Станции для Glagol API |
| `yandex_x_token` | Токен обновления Яндекса; даёт доступ к аккаунту шире одной колонки |
| `station_device_id` | Серийный идентификатор вашей Станции для Glagol |
| `station_platform` | Платформа; для проверенной Станции 2 — `yandexmidi` |
| `client_id.bin`, `private_key.pem` | Собственные разрешённые ресурсы уже авторизованного клиента воспроизведения |

Шаблон JSON: [`deploy/station/config.example.json`](../deploy/station/config.example.json). Локальный установщик сам закрепляет адреса `127.0.0.1`, порт, путь FFmpeg и создаёт случайный `agent_token`, если он отсутствует.

Мод использует протокол, адаптированный из Music Assistant. Первичный вход в Apple Music/Яндекс и получение разрешённой конфигурации должны быть выполнены отдельно. Здесь нет автоматического извлечения зашифрованного хранилища Music Assistant или загрузчика чужих закрытых ресурсов. Не используйте чужие токены или ключи.

Передайте папку только установщику:

```sh
python3 install.py --host 192.168.1.100 --profile ./my-profile
```

Файлы отправляются по SSH в закрытый каталог `private/` на вашей колонке. Репозиторий и release-архив их не содержат. Не загружайте эту папку в GitHub, issues или чат. Не публикуйте снимки настроек с токенами.

## Альтернативный облачный режим

Для legacy-режима `cloud/` отдельно нужны `pubsub-home.json`, Google Cloud Project, webhook/agent-токены и код привязки. Они не требуются при установке мода непосредственно на Станцию с `--no-cloud --local-voice`. Инструкция: [INSTALL.md](INSTALL.md).

## Истечение токенов

Если сервис сообщает, что нужно заново подключить аккаунт, подготовьте обновлённый личный профиль и повторите установку с `--profile`. Не заменяйте весь профиль чужим примером: собственные файлы клиента воспроизведения должны остаться вашими.
