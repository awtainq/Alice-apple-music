# Компактный ARM64 runtime для Станции 2

Подготовлен для уже установленного Entware Python 3.13, aarch64, glibc 2.27.
Это отдельный комплект библиотек и исходников; работающий плеер на VPS не переключался.

Размер файлов около 26 МиБ, архив около 6,5 МиБ. Python, FFmpeg, токены,
ключи аккаунтов, авторизованные закрытые ресурсы и аудиокэш не включены.
Сохранены лицензии зависимостей. Исключены облачные SDK, gRPC, pip,
байткод и Crypto/SelfTest. Поэлементный источник wheels и SHA256 — wheel-manifest.json.

Проверено непосредственно на Станции: Python 3.13.9, импорты всех пяти модулей
плеера, AES и RSA. Пик RSS этой проверки — 51292 КиБ (около 50 МиБ).
Это не замер пиков памяти полного воспроизведения. Воспроизведение на самой
колонке ещё не проверено; для него нужен FFmpeg и настройка авторизованной конфигурации.

Проверка без запуска сервиса и без обращения к аккаунтам:

```sh
PYTHONDONTWRITEBYTECODE=1 /opt/bin/python3 check_runtime.py
```

Перед будущим переносом нужны отдельные локальные настройки адресов, аудиокэша
и чтения голосовых событий. Не запускайте одновременно два управляющих плеера
на одну Станцию. Библиотеки из этого комплекта не копируются поверх системного Python.
