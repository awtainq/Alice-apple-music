# Установщик и релизы

`install.py` запускается на компьютере с Python 3.10+ и OpenSSH. На колонке требуются root и Entware Python 3.13. Для новой установки нужен собственный готовый профиль; для обновления он сохраняется на колонке.

## Как устроено обновление

1. Проверка root, device-tree Станции 2, ARM64, Python и свободного места.
2. Скачивание `manifest.json` и ARM-архива из последнего GitHub Release, сверка SHA-256.
3. Проверка архива: запрещены абсолютные пути, `..`, ссылки и личный профиль внутри релиза.
4. Установка зависимостей через Entware, передача staging-каталога по SSH.
5. Проверка импортов ARM-библиотек без запуска второго плеера.
6. Сохранение личной конфигурации, очереди и прежней версии. Текущий плеер останавливается.
7. Запуск новой версии и проверка API / соединения со Станцией в течение 60 секунд.
8. При неудаче возвращается прежняя версия. После успешной проверки настраивается автозапуск.

Одновременные установки блокируются lock-файлом. Сохраняется одна предыдущая версия. Более старая резервная копия удаляется только после успешного обновления. Диагностические данные не содержат профиля, но не публикуйте полный журнал без проверки.

Установщик не выполняет root, не отключает OTA, не меняет сеть и не устанавливает AirPlay или Luna. Он временно перемонтирует корневую ФС для **своего** файла `/etc/init.d/S99zzalice-music`, затем возвращает `ro`. Чужой автозапуск автоматически не заменяет.

`--check` — чтение совместимости без установки. `--archive` — использовать локальный архив; проверка происхождения локального файла остаётся за владельцем. Скачивание обычного релиза проверяется по опубликованному SHA-256.

## Воспроизводимая сборка

На компьютере с Python и pip:

```sh
python3 scripts/build_release.py --download
```

Скрипт получает закреплённые зависимости из `requirements-station.lock` под **CPython 3.13 / ARM64 / manylinux2014**. Не подставляйте библиотеки своего Mac или x86-сервера. Готовые файлы в `dist/`:

- `alice-music-station-arm64.tar.gz` — плеер и публичные зависимости;
- `manifest.json` — версия, платформа и SHA-256;
- `SHA256SUMS`;
- `install.py`.

Python, FFmpeg, токены, клиентские закрытые ресурсы и аудиокэш в релиз не включаются. Лицензии зависимостей сохраняются в vendor и third_party.

## Ручной откат

Если новая версия не запустилась, установщик делает откат сам. Если нужно вручную вернуться к сохранённой версии, сначала проверьте, что `/data/opt/alice-music.previous` существует. Затем на колонке:

```sh
/data/opt/alice-music/launch.sh stop
# Дождитесь статуса stopped и сохраните неудачную версию под свободным именем.
mv /data/opt/alice-music /data/opt/alice-music.failed
mv /data/opt/alice-music.previous /data/opt/alice-music
/data/opt/alice-music/launch.sh start
```

Не перезаписывайте уже существующий `.failed`: выберите другое имя. Автозапуск обращается к постоянному пути `/data/opt/alice-music`.
