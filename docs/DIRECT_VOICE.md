# Голосовое управление: схема из рецепта Spotify

С версии 0.3.0 музыкальное управление следует простой схеме
[Yandex Station Extended — Spotify](https://hackalice.me/recipes/spotify/):
финальный текст Алисы → разбор музыкальной фразы → команда плееру.

Один Rust-обработчик читает финальный текст и состояние из локального IPC
`127.0.0.1:9875`, как `alice-text` в рецепте. Чтения `maind.log`, отдельного
command spotter и подмены штатных обработчиков SDK больше нет. Повторные
снимки одного запроса не выполняются заново.

Говорите с обращением **«Алиса»**:

| Пример | Действие |
| --- | --- |
| «Алиса, включи песню …» | Поиск песни Apple Music |
| «Алиса, поставь альбом …» | Альбом по порядку |
| «Алиса, включи плейлист …» | Плейлист каталога |
| «Алиса, включи исполнителя …» | Популярные песни исполнителя |
| «Алиса, включи мою музыку» | Медиатека подписки |
| «Алиса, пауза / продолжи / дальше / назад» | Управление активной или недавно использованной очередью |
| «Алиса, что играет?» | Название и исполнитель |
| «Алиса, мне нравится / мне не нравится» | Оценить текущую песню |
| «Алиса, включи понравившиеся песни» | Воспроизвести локальное избранное |
| «Алиса, включи похожие» | Новая очередь рекомендаций |

В отличие от исходного рецепта Spotify, с версии 0.3.4 распознанный
музыкальный запрос отменяет штатный диалог до поиска песни. Поэтому вместо
родного музыкального ответа используется короткое «Включаю [название песни]».
Название берётся из найденного трека Apple Music, а не из исходной фразы.
Объявление добавляется только при голосовом запуске новой песни/подборки;
пауза, продолжение, следующие песни и автоматическая очередь остаются без
дополнительных фраз. С версии 0.3.6 объявление отправляется после подтверждения штатной паузы,
пока аудио ещё готовится, без ожидания старта музыки. Если файл уже в кэше,
короткая фраза может пересечься с началом песни. Во время объявления
приглушается только поток Apple Music.

При передаче штатная консоль Quasar (`maind --cli`) получает обычный ввод
`Player Pause`; плеер ждёт подтверждения SDK и закрывает консоль. Локальный
звук запускается один раз. Это не регистрация Apple Music в облачном каталоге
Алисы. Команды без обращения не перехватываются.

## Задержка запуска

С версии 0.3.5 плеер не ждёт до восьми секунд завершения состояния речи после
отмены диалога. Подготовка AAC идёт одновременно со штатной паузой. Новый
поиск отменяет предзагрузку и рекомендации старой очереди; ограничение частоты
HTTP-запросов разносит их начало, не удерживая блокировку до ответа сервера.

Первая песня по-прежнему требует поиска и загрузки файла. Кэш и предзагрузка
следующей песни ускоряют повторный запуск и переходы, но время зависит от сети.
Журнал содержит длительности `music_search`, `music_prepare`, `music_handoff`
и `music_command` в миллисекундах, без текста запроса и адресов аудио.

## Звук и очередь

Подготовленный AAC декодируется FFmpeg в PCM, который поступает в штатный
`aplay` через общий ALSA PCM `plug:dmix_spk`. Медиа-демон Алисы не убивается.
Glagol не используется ни для запуска, ни для подтверждения, ни для управления
музыкальным потоком. Завершение `aplay` продвигает очередь; пауза завершает оба
дочерних процесса, продолжение открывает файл с сохранённой позиции.

Музыкальный уровень читается из штатного состояния
`/data/quasar/data/last_vendor_volume` по шкале платформы Миди 0–20.
Уровень применяет штатный ALSA Master, общий с Алисой и AirPlay. Плеер
не умножает PCM на этот процент повторно. Нулевое, отсутствующее или
некорректное значение даёт тишину. Отдельный микшер
системной громкости не создаётся, уровень колонки не перезаписывается.
Во время слушания Алисы и озвучивания Gemini приглушается только поток Apple
Music. Восстановление громкости и повторные старты по статусам Glagol удалены.

Если AirPlay активен, очередь уступает ему звук. Отключение телефона само
по себе не возобновляет Apple Music.

## Оценки песен

«Мне нравится» сохраняет текущую песню в локальном избранном. Синонимы:
«Алиса, лайк», «поставь лайк», «лайкни», «добавь в избранное», «добавь в любимые».
Для отрицательной оценки: «Алиса, дизлайк», «поставь дизлайк», «дизлайкни»,
«больше не включай эту песню». «Мне не нравится»
убирает её из избранного и будущей очереди. Если песня играет, плеер переходит
к следующей; на паузе оценка не запускает звук. Если следующая песня недоступна,
оценка остаётся сохранённой, а плеер — на паузе. Ответы короткие: «Запомнила»
и «Больше не предложу».

Оценки хранятся в закрытом `preferences.json` рядом с профилем и переживают
обновления/перезагрузку. В Apple Music они пока не синхронизируются. Нежелательные
песни исключаются из следующих треков и рекомендаций; явный запрос песни или
команда «назад» могут её открыть снова. Новый лайк снимает локальный запрет.
«Алиса, включи понравившиеся песни» запускает сохранённое избранное.
Команды оценки действуют для активной или недавно использованной очереди Apple
Music; AirPlay они не оценивают. Обращение «Алиса» пока обязательно.

## Gemini

Gemini остаётся отдельной необязательной возможностью: погода, умный дом и
команды самой колонки идут Алисе, остальные вопросы — Gemini. Погода и умный дом отбираются до отмены музыкального диалога.
Отмена также используется для собственного ответа Gemini и объявления названия. Тексты вопросов в журнал не пишутся.
