# Голосовое управление: схема из рецепта Spotify

С версии 0.3.0 музыкальное управление следует простой схеме
[Yandex Station Extended — Spotify](https://hackalice.me/recipes/spotify/):
финальный текст Алисы → разбор музыкальной фразы → команда плееру.

Один Rust-обработчик читает финальный текст и состояние из локального IPC
`127.0.0.1:9875`, как `alice-text` в рецепте. Чтения `maind.log`, отдельного
command spotter и подмены штатных обработчиков SDK больше нет. Повторные
снимки одного запроса не выполняются заново.

Говорите с обращением **«Алиса»**:

| Пример | Действие |
| --- | --- |
| «Алиса, включи песню …» | Поиск песни Apple Music |
| «Алиса, поставь альбом …» | Альбом по порядку |
| «Алиса, включи плейлист …» | Плейлист каталога |
| «Алиса, включи исполнителя …» | Популярные песни исполнителя |
| «Алиса, включи мою музыку» | Медиатека подписки |
| «Алиса, пауза / продолжи / дальше / назад» | Управление активной или недавно использованной очередью |
| «Алиса, что играет?» | Название и исполнитель |
| «Алиса, включи похожие» | Новая очередь рекомендаций |

Как и в рецепте, Алиса обрабатывает музыкальную фразу штатно. До передачи звука
локальному плееру она может произнести свой ответ или ненадолго включить
Яндекс Музыку. При передаче штатная консоль Quasar (`maind --cli`) получает обычный ввод
`Player Pause`; плеер ждёт подтверждения SDK и закрывает консоль. Затем
локальный звук запускается один раз. Самодельный музыкальный RPC удалён. Это не интеграция Apple Music
в облачный каталог Алисы. Команды без обращения не перехватываются.

## Звук и очередь

Подготовленный AAC декодируется FFmpeg в PCM, который поступает в штатный
`aplay` через общий ALSA PCM `plug:dmix_spk`. Медиа-демон Алисы не убивается.
Glagol не используется ни для запуска, ни для подтверждения, ни для управления
музыкальным потоком. Завершение `aplay` продвигает очередь; пауза завершает оба
дочерних процесса, продолжение открывает файл с сохранённой позиции.

Музыкальный уровень читается из штатного состояния
`/data/quasar/data/last_vendor_volume` по шкале платформы Миди 0–20.
Нулевое, отсутствующее или некорректное значение даёт тишину. Отдельный микшер
системной громкости не создаётся, уровень колонки не перезаписывается.
Во время слушания Алисы и озвучивания Gemini приглушается только поток Apple
Music. Восстановление громкости и повторные старты по статусам Glagol удалены.

Если AirPlay активен, очередь уступает ему звук. Отключение телефона само
по себе не возобновляет Apple Music.

## Gemini

Gemini остаётся отдельной необязательной возможностью: погода, умный дом и
команды самой колонки идут Алисе, остальные вопросы — Gemini. Отмена диалога
используется только для собственного ответа Gemini и объявления названия,
а не для музыкального транспорта. Тексты вопросов в журнал не пишутся.
