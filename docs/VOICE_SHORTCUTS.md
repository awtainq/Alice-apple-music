# Короткие команды после завершения сессии

Яндекс может завершить сессию навыка после молчания, хотя музыка продолжает играть. Тогда «дальше» попадает во встроенный плеер Алисы, а не в этот навык.

Для постоянных коротких команд создайте голосовые сценарии в **«Доме с Алисой»**. Они заново передадут нужную команду навыку. Запросы произвольных новых песен по-прежнему нужно отправлять из открытого навыка или с его именем.

## Настройка в приложении

Для каждой строки таблицы создайте отдельный сценарий:

1. Нажмите **«+» → «Сценарий»**.
2. В **«Если» → «Фраза»** добавьте короткую фразу без слова «Алиса».
3. В **«Тогда»** выберите конкретную Станцию → **«Выполнить команду»**.
4. Укажите полную команду из таблицы. Если имя вашего навыка другое, замените «моя фонотека».
5. Сохраните. При наличии нескольких колонок ограничьте запуск нужной комнатой и выберите соответствующую Станцию в действии.

| Голосовая фраза | Команда Станции в сценарии |
| --- | --- |
| дальше / следующая / следующая песня | скажи навыку моя фонотека дальше |
| предыдущая / предыдущая песня | скажи навыку моя фонотека предыдущая |
| пауза | скажи навыку моя фонотека пауза |
| продолжай / продолжи музыку | скажи навыку моя фонотека продолжай |
| включи похожие | скажи навыку моя фонотека включи похожие |
| что за песня сейчас играет / что играет | скажи навыку моя фонотека что играет |

Фраза должна быть свободна от других сценариев в той же комнате. Эти сценарии адресуют команды именно вашей фонотеке, в том числе когда она закрыта. Учитывайте это при использовании других музыкальных сервисов на той же колонке. Для отключения удалите или выключите только созданные музыкальные сценарии.

## Проверка

Выйдите из навыка, затем скажите «Алиса, дальше». Следующая песня должна запуститься без произнесения имени навыка. Аналогично проверьте паузу и продолжение.

[Официальная инструкция Яндекса](https://alice.yandex.ru/support/ru/smart-home/scenarios/voice).

Запрос названия не переключает песню: после голосового ответа плеер продолжит текущий трек. Если вы заранее поставили музыку на паузу, запрос названия не снимает её с паузы.

Остановленный после голосового ответа поток открывается повторно из кэша с восстановлением позиции. Это обходит нестабильное поведение нативного `play` на внешнем аудиопотоке.
