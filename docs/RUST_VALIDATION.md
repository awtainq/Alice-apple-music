# Проверка версии 0.3.4

Управление переписано по схеме рецепта Spotify на hackalice. Музыка выводится
через FFmpeg/ALSA/aplay, без Glagol и чтения журнала команд.

- 33 теста плеера, 3 теста импортера и 4 теста упаковщика проходят.
- Тесты аудиопроцессов используют подставные декодер и приёмник: проверяют EOF,
  остановку, освобождение процессов, позицию и ослабление PCM без вывода звука.
- Тесты маршрутизации подтверждают отмену штатного диалога до передачи
  музыкальной команды и отсутствие отмены для погоды. Название для короткого
  объявления ограничивается по длине и очищается от разметки.
- Штатная консоль на колонке подтвердила `Player Pause` без запуска музыки.
  Два теста проверяют отправку только паузы/выхода и обработку отсутствующего подтверждения.
- Clippy не сообщает предупреждений; ARM64/musl пакет собирается штатным скриптом.
- Установка запускается в паузе. Gemini сохранён. Профиль хранится вне пакета.
- В 0.3.4 устранено двойное ослабление: штатный ALSA Master управляет уровнем,
  PCM не умножается на тот же процент повторно. Ноль и недоступное значение
  по-прежнему означают тишину. Регрессионный тест проверяет сохранение PCM
  при положительном штатном уровне и дополнительное ослабление только для лимита.
- После просьбы владельца не включать звук автоматические звуковые проверки не проводились.
  Голосовое воспроизведение, переход к следующей песне и громкость этой версии
  требуют последующей проверки владельцем. Это не подтверждение их работы на слух.

Ниже сохранены исторические замеры бэкенда до 0.3.0; они не описывают текущий
расход памяти или поведение ALSA.

# Проверка на колонке

29 октября 2026 года: рутованная Станция Миди, `yandex,station-midi`, ARM64,
firmware `0.372.1.8.4790676133.20261019.298`. Luna — ветка PR nyakokitsu/luna#3;
FFmpeg Entware 6.1.4.

- Rust-клиент самостоятельно нашёл и подготовил Babydoll — Dominic Fike.
- `.yap` установлен через Luna; runtime token и соединение со Станцией проверены.
- Подтверждены воспроизведение и загрузка локального AAC колонкой.
- Владелец подтвердил переключение словом «дальше» и озвучивание названия.
- После окончания песни автоматически запущена следующая рекомендация.
- Профиль и очередь сохраняются вне обновляемого пакета.
- Luna и AirPlay работают рядом, rootfs остаётся read-only.

RSS процесса после подготовки песни — около 5 МиБ. Приложение — около 5,5 МиБ,
пакет — около 2,5 МиБ. Это замеры одной установки, не максимальный расход с
FFmpeg, Luna и аудиокэшем.

Автоматически проверяются разбор IPC и повреждённых кадров, музыкальный
маршрутизатор, авторизация API и аудио, HTTP Range, каталог/медиатека и сборщик
пакета. Используются `cargo test --workspace` и Clippy с `-D warnings`.

Полная перезагрузка и суточный прогон не выполнялись. AirPlay/native_volume
ранее подтверждены владельцем; после последнего обновления полный повторный
тест AirPlay владельцем ещё не подтверждён.
