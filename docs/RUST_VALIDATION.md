# Проверка на колонке

29 октября 2026 года: рутованная Станция Миди, `yandex,station-midi`, ARM64,
firmware `0.372.1.8.4790676133.20261019.298`. Luna — ветка PR nyakokitsu/luna#3;
FFmpeg Entware 6.1.4.

- Rust-клиент самостоятельно нашёл и подготовил Babydoll — Dominic Fike.
- `.yap` установлен через Luna; runtime token и соединение со Станцией проверены.
- Подтверждены воспроизведение и загрузка локального AAC колонкой.
- Владелец подтвердил переключение словом «дальше» и озвучивание названия.
- После окончания песни автоматически запущена следующая рекомендация.
- Профиль и очередь сохраняются вне обновляемого пакета.
- Luna и AirPlay работают рядом, rootfs остаётся read-only.

RSS процесса после подготовки песни — около 5 МиБ. Приложение — около 5,5 МиБ,
пакет — около 2,5 МиБ. Это замеры одной установки, не максимальный расход с
FFmpeg, Luna и аудиокэшем.

Автоматически проверяются разбор IPC и повреждённых кадров, музыкальный
маршрутизатор, авторизация API и аудио, HTTP Range, каталог/медиатека и сборщик
пакета. Используются `cargo test --workspace` и Clippy с `-D warnings`.

Полная перезагрузка и суточный прогон не выполнялись. AirPlay/native_volume
ранее подтверждены владельцем; после последнего обновления полный повторный
тест AirPlay владельцем ещё не подтверждён.
