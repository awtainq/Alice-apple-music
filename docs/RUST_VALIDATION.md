# Проверка Rust / Luna 0.2.0

Дата: 29 октября 2026 года. Устройство: рутованная Станция 2,
`yandex,station-midi`, ARM64, firmware `0.372.1.8.4790676133.20261019.298`.
Luna — проверенная ветка PR nyakokitsu/luna#3; FFmpeg Entware 6.1.4.

- Нативный Rust-клиент самостоятельно нашёл и подготовил Babydoll — Dominic Fike.
- `.yap` установлен через Luna; запуск с выданным runtime token проверен.
- API колонки подтвердил playing и получение локального AAC (HTTP GET).
- Автопереход после окончания песни проверен: счётчик auto_advances вырос,
  следующая песня запущена и загружена колонкой без команды пользователя.
- Пользователь подтвердил переключение словом «дальше» и озвучивание названия
  командой «Алиса, что играет?».
- Отказ первого пробного запуска проверил автоматический возврат Python-сервиса.
- После успешного переноса по просьбе владельца старый плеер, его init,
  диагностические копии и все пакеты Python удалены с колонки.
- Luna и AirPlay остались запущены; rootfs возвращён в read-only.
- Профиль и очередь сохранены отдельно от пакета; закрытая резервная копия
  миграции хранится на компьютере владельца, в релиз не включена.

## Измерения

RSS по `/proc/<pid>/status`: Python 60000 КиБ, Rust 5388 КиБ.
Экономия — 54612 КиБ (53,3 МиБ), около 91%. Это состояние после подготовки
песни, не максимальный расход с FFmpeg и аудиокэшем.

`du -sk`: старое приложение 29016 КиБ, Rust-пакет 5624 КиБ;
отдельная библиотека Python занимала около 16356 КиБ.
После очистки UBI сообщил около 137 МиБ свободного места.

## Автоматическая проверка

Rust unit/integration tests: разбор IPC и повреждённых кадров, консервативный
маршрутизатор голоса, принадлежность команд локальной очереди, каталог/медиатека,
авторизация API и аудио, HTTP Range. Clippy с `-D warnings`.

Перезагрузка всей колонки и длительный тест в течение суток не выполнялись.
AirPlay/native_volume ранее подтверждены владельцем; полный повторный тест
AirPlay после удаления Python ещё не подтверждён владельцем.
