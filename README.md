## Музыка без отдельного сервера

Неофициальный мод для **Яндекс Станции Миди с root, Entware и Luna**.
Один нативный процесс Rust: поиск в подписке Apple Music, очередь,
предзагрузка следующей песни и автоматическое продолжение рекомендациями.

> «Алиса, включи песню Babydoll Dominic Fike» → играет песня.
>
> Просто «дальше» → следующий трек из очереди Apple Music.

| Возможность | Что происходит |
| --- | --- |
| Поиск по голосу | Песня, исполнитель, альбом, плейлист каталога или медиатека |
| Похожие песни | Рекомендации Apple Music после окончания очереди |
| Короткие команды | «Дальше», «назад», «пауза», «играй» без имени навыка |
| Название трека | «Алиса, что играет?» — название и исполнитель |
| Меньше фраз | Включение и переключение без голосовых подтверждений |
| Пакет Luna | Установка `.yap`, управление сервисом и автозапуск |
| Совместимость с AirPlay | Подключённый телефон получает приоритет звука и команд |
| Хранение | Аудиокэш в RAM, профиль и очередь отдельно от пакета |

## Установка через Luna

Нужны root, ARM64 Entware с `/opt/bin/ffmpeg` и Luna с поддержкой локальных
binary-service `.yap`. В Luna должно быть разрешено `allow_plugin_binaries = true`.
Проверено на Станции Миди с device tree `yandex,station-midi` (Luna: `yandexmidi`).
Другие модели пока не проверены.

1. Скачайте **`alice-apple-music-luna-0.2.2-aarch64.yap`** из
   [Releases](https://github.com/awtainq/Alice-apple-music/releases/latest).
2. В Luna откройте **«Установка .yap»**, выберите файл и загрузите его.
3. При первой установке добавьте собственный [профиль Apple Music и Яндекса](docs/AUTH.md)
   в `/data/opt/luna/data/apple-music-private`.
4. Включите сервис **Alice × Apple Music** (`alice-apple-music`) в Luna.

**При обновлении профиль добавлять заново не нужно.** Остановите сервис,
загрузите новый `.yap` и включите его снова. Очередь сохранится и восстановится
на паузе; для воспроизведения скажите «Алиса, продолжай».

Если интерфейс Luna отключён, тот же `.yap` можно загрузить через её локальный
API по SSH-туннелю. Команды — в [инструкции установки](docs/INSTALLER.md).
API плеера и Luna не требуется открывать в домашнюю сеть.

## Пакет YAM

Для реестра подготовлен `awtainq/apple-music`: готовый `.yap` и нативная
команда его импорта в Luna.

```sh
yam install awtainq/apple-music
awtainq-apple-music
```

После добавления личного профиля выполните `awtainq-apple-music --enable-only`.
Если профиль уже готов, используйте `awtainq-apple-music --enable` для импорта
и запроса запуска одной командой. API Luna должен слушать отдельный порт,
по умолчанию `127.0.0.1:8098`.

YAM устанавливает файлы пакета, но не запускает сервисы. Импортированным `.yap`
и автозапуском плеера управляет Luna. [Подробности и удаление](yam/README.md).

## Голосовые команды

| Скажите | Результат |
| --- | --- |
| «Алиса, включи песню …» | Поиск песни |
| «Алиса, включи исполнителя …» | Песни исполнителя |
| «Алиса, включи альбом …» | Альбом по порядку |
| «Алиса, включи плейлист …» | Плейлист каталога |
| «Алиса, включи мою музыку» | Личная медиатека подписки |
| «Дальше» / «назад» | Следующая / предыдущая песня |
| «Пауза» / «играй» | Остановка / продолжение |
| «Алиса, что играет?» | Название и исполнитель |
| «Алиса, включи похожие» | Новая очередь рекомендаций |

Входить в навык не нужно. Свет, таймеры, радио и громкость остаются у Алисы.
При активном AirPlay транспортом телефона управляет Luna; после отключения
телефона локальная очередь сама не стартует.

## Ресурсы

На проверенной Станции Миди процесс занимал около **5 МиБ ОЗУ**, приложение —
около **5,5 МиБ**, пакет — около **2,5 МиБ**. Это замеры одной установки,
не пиковое потребление. Отдельно расходуют память Luna, аудиокэш и FFmpeg
при подготовке песни. AAC копируется без перекодирования.
