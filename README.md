## Что это

Неофициальный мод для **Яндекс Станции 2 с root и Entware**. Плеер получает музыку из вашей подписки Apple Music, хранит очередь, заранее готовит следующую песню и выполняет музыкальные команды Алисы. Всё работает на самой колонке одним процессом Python.

> «Алиса, включи песню Babydoll Dominic Fike» → играет песня, затем похожие.
>
> Просто «дальше» → следующий трек из той же очереди.

| Возможность | Как работает |
| --- | --- |
| Поиск музыки | Песня, исполнитель, альбом, плейлист каталога или личная медиатека |
| Автопродолжение | После песни — рекомендации Apple Music |
| Короткие команды | «Дальше», «назад», «пауза», «играй» — в том числе без слова «Алиса» |
| Название трека | «Алиса, что играет?» — название и исполнитель |
| Автозапуск | Supervisor запускается вместе с колонкой и перезапускает процесс после сбоя |
| Бережное хранение | Аудиокэш и ограниченные журналы находятся в RAM |
| Обновления | Установщик сохраняет личный профиль и предыдущую версию; при ошибке запуска делает откат |
| AirPlay рядом | При установленном совместимом приёмнике плеер уступает звук телефону |

## Проверенная конфигурация

**Станция 2 (`yandex,station-midi`), ARM64, Entware Python 3.13, glibc 2.27, FFmpeg 6.1.4.** Это не розничная Станция Миди. Другие модели этим релизом не заявлены совместимыми.

В проверенной установке процесс занимал около **57 МиБ ОЗУ**, код с библиотеками — около **28 МиБ**, архив — около **6,5 МиБ**. Python и FFmpeg устанавливаются отдельно. Это измерения одной установки, а не максимальное потребление при любых песнях и очередях.

## Установка

Установщик запускается **на компьютере**, колонка доступна по SSH. Нужны Python 3.10+ и OpenSSH на компьютере, root и Entware Python 3.13 на Станции. Получение root и установка Entware не выполняются этим модом.

### 1. Подготовьте личный профиль

Для первой установки нужна папка с тремя файлами:

```text
my-profile/
├── config.json       # собственные авторизованные токены Apple Music и Яндекса
├── client_id.bin     # собственные разрешённые ресурсы авторизованного клиента
└── private_key.pem
```

Шаблон: [`deploy/station/config.example.json`](deploy/station/config.example.json). Требования и ограничения: **[Авторизация](docs/AUTH.md)**.

**Мастер входа в аккаунты и выдача ресурсов декодера в комплект не входят.** Установщик импортирует ваш готовый личный профиль. Чужие ключи, токены и аудиофайлы не распространяются.

### 2. Запустите установщик

Скачайте его из этого репозитория или клонируйте проект:

```bash
curl -fsSL https://raw.githubusercontent.com/awtainq/Alice-apple-music/main/install.py -o install.py
python3 install.py --host 192.168.1.100 --profile ./my-profile
```

Замените адрес на IP своей Станции. Порт SSH по умолчанию `2222`; для другого добавьте `--port`.

Установщик проверяет модель, Python и свободное место, сверяет SHA-256 скачанного релиза, ставит зависимости через Entware, переносит приложение и проверяет соединение со Станцией. Файлы профиля передаются по SSH. Перезагрузка не нужна.

### Уже установлено? Обновите без повторной авторизации

```bash
python3 install.py --host 192.168.1.100
```

Профиль и очередь сохраняются на колонке. Обновление перезапускает плеер и оставляет очередь на паузе — затем скажите «Алиса, продолжай». При активном AirPlay очередь также остаётся приостановленной.

Проверка совместимости без изменений:

```bash
python3 install.py --host 192.168.1.100 --check
```

Офлайн-установка из заранее скачанного релиза:

```bash
python3 install.py --host 192.168.1.100 \
  --archive ./alice-music-station-arm64.tar.gz --profile ./my-profile
```

Офлайн-архив не отменяет необходимость установить зависимости Entware и иметь интернет для музыки. `--skip-deps` подходит, если зависимости уже установлены.

## Голосовые команды

| Скажите | Результат |
| --- | --- |
| «Алиса, включи песню …» | Поиск песни, затем похожая музыка |
| «Алиса, включи исполнителя …» | Песни исполнителя |
| «Алиса, поставь альбом …» | Альбом по порядку |
| «Алиса, включи плейлист …» | Плейлист из каталога |
| «Алиса, включи мою музыку» | Песни вашей медиатеки |
| «Дальше» / «назад» | Следующий / предыдущий трек |
| «Пауза» / «играй» | Приостановка / продолжение |
| «Алиса, включи похожие» | Новые рекомендации по текущему треку |
| «Алиса, что за песня сейчас играет?» | Название и исполнитель |

Имя навыка не нужно. Распознавание речи, таймеры, умный дом и громкость обслуживает штатная Алиса. Плеер отбирает музыкальные команды из её локального канала; короткие слова получает из локального command spotter. Сырое аудио микрофонов мод не записывает.

## Управление и откат

На колонке:

```sh
/data/opt/alice-music/launch.sh status
/opt/bin/python3 /data/opt/alice-music/control.py pause
/opt/bin/python3 /data/opt/alice-music/control.py resume
tail -20 /tmp/alice-music.log
```

После обновления предыдущая версия лежит в `/data/opt/alice-music.previous`. [Подробности хранения, автозапуска и ручного отката](docs/STATION_INSTALL.md).

## Ограничения

- Нужны действующая подписка и собственная авторизованная конфигурация. Токены могут истечь.
- Протоколы неофициальные; обновление прошивки или сервисов может нарушить работу.
- Это полноценный приёмник Apple Music по голосу, но не AirPlay-приёмник. [AirPlay устанавливается отдельно](docs/AIRPLAY_COEXISTENCE.md).
- Личные закрытые плейлисты пока не ищутся. Загруженные в iCloud файлы без каталожного ID пропускаются.
- До 500 уникальных треков в выбранном списке; затем рекомендации. Бесшовное воспроизведение не гарантируется.
- Кэш обычно содержит текущую и следующую песни. Загрузка одного файла ограничена 32 МиБ.
- Текущая проверенная установка восстанавливает очередь на паузе после перезапуска. Холодный старт после аппаратной перезагрузки отдельно не проверялся.
