## Музыка без отдельного сервера

Неофициальный мод для **Яндекс Станции 2 с root, Entware и Luna**.
Плеер ищет музыку в вашей подписке Apple Music, заранее готовит следующую
песню и продолжает похожими треками. Один нативный процесс Rust; Python,
Docker, VPS и облачный навык для воспроизведения не нужны.

> «Алиса, включи песню Babydoll Dominic Fike» → играет песня.
>
> Просто «дальше» → следующий трек из очереди Apple Music.

| Возможность | Что происходит |
| --- | --- |
| Музыка по голосу | Песня, исполнитель, альбом, плейлист каталога или медиатека |
| Похожие песни | Рекомендации Apple Music после окончания очереди |
| Короткое управление | «Дальше», «назад», «пауза», «играй» без имени навыка |
| Название трека | «Алиса, что играет?» — название и исполнитель |
| Без лишних фраз | Успешные включения и переключения без голосовых подтверждений |
| Luna | Установка `.yap`, запуск, остановка и автозапуск как binary service |
| AirPlay | При подключении телефона локальная очередь уступает ему звук и команды |
| Хранение | Аудиокэш в RAM, профиль и очередь отдельно от обновляемого пакета |

## Расход ресурсов

На проверенной Станции 2 после подготовки песни:

| | Python 0.1.x | Rust 0.2.0 |
| --- | ---: | ---: |
| RSS процесса | 58,6 МиБ | 5,3 МиБ |
| Приложение с библиотеками | 28,3 МиБ | 5,5 МиБ |
| Архив установки | около 6,5 МиБ | около 2,5 МиБ |
| Python на колонке | нужен | не нужен |

Это замеры одной установки, не пиковые значения. Дополнительно расходуют память
аудиокэш, FFmpeg при подготовке песни и сама Luna. FFmpeg копирует AAC без
перекодирования. Python runtime прежней установки занимал ещё около 16 МиБ.

## Установка

Проверено на **Станции 2** с device tree `yandex,station-midi`, ARM64 и
FFmpeg 6.1.4. В Luna эта модель определяется как `yandexmidi`; это не заявление
о поддержке розничной Станции Миди. Другие модели пока не проверены.

Нужны root, SSH, Entware `/opt/bin/ffmpeg` и Luna с поддержкой **локальных
binary-service `.yap`**, `allow_plugin_binaries = true`. Получение root и
установка Entware/Luna выполняются отдельно. Проверялась ветка Luna с
[поддержкой AirPlay](https://github.com/nyakokitsu/luna/pull/3).

1. Скачайте из [Releases](https://github.com/awtainq/Alice-apple-music/releases)
   пакет `alice-apple-music-luna-0.2.0-aarch64.yap`, его `.sha256` и исходники.
2. Для новой установки подготовьте собственный профиль по [AUTH.md](docs/AUTH.md).
3. На компьютере с Python **3.11+** и OpenSSH выполните из папки исходников:

```sh
python3 rust/install-luna.py --host IP_КОЛОНКИ --port 2222 \
  --package alice-apple-music-luna-0.2.0-aarch64.yap \
  --profile /путь/к/my-profile
```

При переходе с Python-версии на той же колонке **не указывайте `--profile`**:
установщик перенесёт профиль и очередь из `/data/opt/alice-music/private`.
После успешного перехода старые файлы остаются для отката. Python и прежний
плеер можно удалить отдельно, убедившись, что они не нужны другим модам.
На колонке Python для Rust-плеера не требуется; установщик работает на ПК.

Установщик использует временный SSH-туннель к локальной Luna, проверяет пакет
и соединение с колонкой. При ошибке запуска возвращает предыдущий сервис.
Откат к сохранённому Python-плееру:

```sh
python3 rust/install-luna.py --host IP_КОЛОНКИ --rollback-python
```

Откат доступен, пока старый плеер и его Python не удалены. Профиль Rust хранится
в `/data/opt/luna/data/apple-music-private` и не удаляется при обновлении `.yap`.

## Голосовые команды

| Скажите | Результат |
| --- | --- |
| «Алиса, включи песню …» | Поиск песни |
| «Алиса, включи исполнителя …» | Песни исполнителя |
| «Алиса, включи альбом …» | Альбом по порядку |
| «Алиса, включи плейлист …» | Плейлист каталога |
| «Алиса, включи мою музыку» | Личная медиатека подписки |
| «Дальше» / «назад» | Следующая / предыдущая песня |
| «Пауза» / «играй» | Остановка / продолжение |
| «Алиса, что играет?» | Название и исполнитель |
| «Алиса, включи похожие» | Новая очередь рекомендаций |

Команды работают без входа в навык. Общие команды Алисы — свет, таймеры,
радио, громкость — остаются у Алисы. При активном AirPlay транспортом телефона
управляет Luna; после отключения телефона локальная очередь сама не стартует.

## Устройство проекта

- [rust/](rust/) — нативный плеер, пакет Luna, установщик, тесты и сборка.
- [docs/AUTH.md](docs/AUTH.md) — собственные токены и профиль подписки.
- [docs/RUST_VALIDATION.md](docs/RUST_VALIDATION.md) — проверка на колонке и замеры.
- [docs/AIRPLAY_COEXISTENCE.md](docs/AIRPLAY_COEXISTENCE.md) — совместная работа с AirPlay.
- Python-файлы в корне — прежняя реализация 0.1.x, в `.yap` не входят.
  Её стабильный релиз: [v0.1.1](https://github.com/awtainq/Alice-apple-music/tree/v0.1.1).

Сборка и локальный API описаны в [rust/README.md](rust/README.md).
Пакет для Luna устанавливается локально. Публикация binary-пакета в YAM v2
пока не выполнена: проверенная Luna намеренно отклоняет такой тип из YAM.
